# Exercises — What A Design Is For, And How To Run A Design Discussion

Lesson `m01l01` · [Watch](https://learnsome.tech/courses/systemdesign-course/watch?lesson=m01l01)

## Exercise 1: Run the first ten minutes

1. Take one product you use daily. Write its four design questions as questions.
2. Answer only the first two, with numbers you can defend out loud.
3. Write one decision record: context, decision, rejected, consequence.
4. Now say which requirement would change your decision if it doubled.

> **Hint**: If a number is hard to guess, guess an order of magnitude and label it a guess. A labelled guess is usable; an unlabelled one is a trap.
